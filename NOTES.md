# Ossuary Atelier — project notes

Last updated: 2026-10-12. Site: https://ossuaryphuket.me/

## What this is
Static multi-page site for Ossuary Atelier, a Phuket secondhand studio and Phuket thrift culture guide. Sections: homepage (`index.html`), shop (`shop.html`) + item story pages (`ITEM-*.html`), Phuket Thrift Guide (`guide/`), interactive map / slang glossary / beach game / fretboard tools (`tools/`), blog (`blog/`, English) + bilingual Thai/English posts, plus about / how-it-works / contact / privacy / tos / support / partnership / craft / drops.

Vanilla HTML/CSS/JS generated by a Node builder (`scripts/build.mjs`) that injects shared partials into slot markers (`@@NAV_SLOT@@`, `@@FOOTER_SLOT@@`). Data-driven shop backed by `_data/items.json` (8 pieces). Images optimized to WebP by `scripts/optimize-images.mjs`.

## Deploy pipeline
- Push to `main` → GitHub Actions (`.github/workflows/pages.yml`) → build with asset fingerprinting → deploy to GitHub Pages → Cloudflare cache purge via API.
- Secrets: `GITHUB_TOKEN` (built-in); `CLOUDFLARE_API_TOKEN` (scoped) + `CLOUDFLARE_ZONE_ID`.
- Zone ID `f9cb4ec7b64ec411ec5ead0ef1da36ad` never changes.
- Cloudflare: Free plan, SSL Full(strict), Brotli + HTTP/3 on, Rocket Loader OFF, `www` CNAME → apex (proxied), cert = Let's Encrypt. Domain DNS managed at Cloudflare (Namecheap NS pointed there).

## Cloudflare rules (set via dashboard/API)
- **Transform Rule** (adds 5 security headers, expression `true`):
  `Strict-Transport-Security: max-age=31536000; includeSubDomains; preload`, `X-Content-Type-Options: nosniff`, `X-Frame-Options: SAMEORIGIN`, `Referrer-Policy: strict-origin-when-cross-origin`, `Permissions-Policy: camera=(), geolocation=(), microphone=(), payment=(), usb=()`.
- **Cache Rules** (phase `http_request_cache_settings`):
  1. `starts_with(http.request.uri.path, "/.well-known/")` → `cache:false` (bypass).
  2. everything else → `cache:true`, edge TTL `override_origin` 2,678,400s (200–299), browser TTL override 2,678,400s.
- HTML pages still report `cf-cache-status: DYNAMIC` (Pages default) but send `Cache-Control: max-age=600`; fingerprinted assets are `HIT` with `Cache-Control: max-age=2678400`.
- Purge runs automatically on each deploy (workflow step, `continue-on-error` — it never fails a build).

## Build discipline (how we ship)
1. `node scripts/build.mjs --enable-content` run **twice**; the 2nd run must print `0 rewritten` everywhere (idempotency check).
2. `npm run verify` → `999 passed, 0 failed`.
3. `npm run --silent links:strict` → `0 broken`.
4. Commit + push to `main` (auto-deploys + auto-purges).
5. Always curl-verify the live site afterwards (headers + on-page content, since scans can be stale).
- Build scope: 8 item story pages, 15 partial rewrites, ~80 SEO pages, 210 fingerprinted assets, sitemap (76 urls) + robots.txt + llms.txt.
